# fe-hands-on-set3

Timed front-end interview exercise built with Vite, React, TypeScript, React Router and TanStack Query.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm test         # run the test suite once
npm run test:watch
npm run lint
npm run build
```
